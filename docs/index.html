Features

You can use it without an account, and it works offline.

Sync across browsers

Sign in with Google on each browser you use. Changes sync automatically, and existing links are merged when you sign in.

Categories

Group links by topic, give each group a colour and drag to reorder.

Right-click to save

Save the current page to a category from the context menu.

Search

Find a link by its address or description as you type.

Done checkboxes

Tick off what you have read or finished.

Inline editing

Edit a link or category directly in the list.

Open or copy

Open a link in a new tab or copy its address in one click.

Export and import

Back up everything to a JSON file and restore it later.

Where your links are stored

Links are stored in your browser. If you sign in, the extension also keeps them in a Google Sheet in your Drive and talks to Google directly.

Google permissions

Google asks for these only if you sign in.

openid email profile

Name, email and profile photo

Shown in the popup so you can see which account is syncing, and used to keep sync on that account.

drive.file

Only the file the extension creates

Lets the extension create and update its sheet, "Link Inventory Extension [Dont delete]". It cannot see or change your other Drive files.

Install

Install from the Chrome Web Store in one click. To load it from source instead, follow these steps.

  1. DownloadDownload the ZIP and unzip it.
  2. Open extensionsGo to chrome://extensions and turn on Developer mode.
  3. Load itClick "Load unpacked" and choose the unzipped folder.
  4. Sign in (optional)Click "Sign In" in the popup to start syncing.
